# 🎖️ Simulador de Alistamento Militar

Projeto desenvolvido em **Python** como exercício de lógica de programação, estruturas condicionais e utilização de data.

O programa recebe o gênero e o ano de nascimento do usuário e realiza uma análise simples para informar a situação relacionada à idade para o alistamento.

## 🎯 Objetivo

Praticar conceitos fundamentais de Python desenvolvendo uma aplicação capaz de:

- Receber informações do usuário;
- Trabalhar com diferentes condições;
- Calcular a idade com base no ano atual;
- Informar diferentes situações de acordo com a idade;
- Utilizar a biblioteca `datetime`.

## 🛠️ Tecnologias

- Python 3
- PyCharm
- Biblioteca `datetime`

## 📚 Conceitos praticados

- Importação de bibliotecas
- Entrada de dados com `input()`
- Conversão de tipos
- Manipulação de strings
- Estruturas condicionais (`if`, `elif`, `else`)
- Operações matemáticas
- Utilização de `date.today()`

## ⚙️ Como funciona

O programa solicita:

1. Gênero;
2. Ano de nascimento.

A partir dessas informações, calcula a idade utilizando o ano atual e apresenta uma mensagem correspondente à situação identificada pelo programa.

## 💻 Exemplo

```text
Qual é o seu gênero?
Digite F para feminino e M para masculino: M

Qual o ano de nascimento? 2010

Você tem 16 anos
Você precisará se alistar em 2 anos
No ano de 2028
```
